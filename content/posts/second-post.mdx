## Why TanStack Router?

When picking a router for this blog, I wanted something with:

1. **Type safety** — full TypeScript inference for params and search params
2. **File-based routing** — convention over configuration
3. **Built-in code splitting** — lazy loading routes out of the box

TanStack Router checks all of these boxes.

## File-based routing

The route structure maps directly to the file system:

```
src/routes/
├── __root.tsx      → Layout wrapper
├── index.tsx       → /
└── blog/
    ├── index.tsx   → /blog
    └── $slug.tsx   → /blog/:slug
```

Each file exports a `Route` object created with `createFileRoute`. The router plugin generates the route tree automatically.
